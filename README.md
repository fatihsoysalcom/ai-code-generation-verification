# AI Code Generation Verification

This Python script demonstrates a simplified workflow of AI-assisted code generation and verification. It simulates an AI generating Python code snippets based on descriptions and then verifies if the generated code contains the expected function.

## Language

`python`

## How to Run

Save the code as `verify_ai_code.py` and run it from your terminal using: `python verify_ai_code.py`
